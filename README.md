# Discord AI Bot (Chat, Coding & Image Generation)

بوت ديسكورد متطور وسريع جداً يعتمد على الذكاء الاصطناعي (Groq Llama 3 & Pollinations) لدعم الدردشة، البرمجة، وتوليد الصور مجاناً.

## المميزات
- **نظام الغرف المخصصة:** يمكنك تحديد غرفة معينة للذكاء الاصطناعي باستخدام أمر `!set-ai-channel`.
- **نظام المواضيع (Threads):** يقوم البوت بفتح Thread خاص لكل مستخدم لضمان تنظيم الدردشة.
- **توليد الصور:** استخدم `صورة: وصف الصورة` أو `تخيل: وصف الصورة` لتوليد صور مجانية فورية.
- **خبير برمجة:** البوت مبرمج ليكون خبيراً في الكود وحل المشكلات التقنية.

## طريقة التشغيل
1. قم بتثبيت المكتبات: `pnpm install`
2. ضع التوكن الخاص بك في ملف `.env`.
3. شغل البوت: `node index.js`

## الأوامر
- `!set-ai-channel`: لتحديد الغرفة الحالية كغرفة للذكاء الاصطناعي.
- اكتب أي رسالة في الغرفة المحددة لبدء دردشة في Thread جديد.
- داخل الـ Thread، يمكنك الاستمرار في الدردشة أو طلب صور.
